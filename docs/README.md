## One screen

shannon-autograd is an experimental differentiable GPU computing SDK in Rust.
A kernel is an ordinary Rust function in `shannon-core`; the same body is
compiled ahead-of-time to PTX (via cuda-oxide) and to a rayon CPU backend, and
the two backends are held to agreement by tests before any number is timed.
Reverse-mode autodiff works over a borrow-scoped tape of launches: records
hold shared borrows so taped buffers cannot be mutated, and `backward`
consuming the tape is what re-permits the optimizer's mutation. Gradients flow
through imperative spatial queries (BVH closest-point) by requerying
correspondence untaped and applying the envelope theorem. Three defining
properties: **every line of math lives in one `no_std` crate**, **forward
kernels are race-free by their output type**, and **the project measures
rather than claims**.

## Key numbers

Reproduced with methodology in [RESULTS.md](RESULTS.md); tests and lint
re-runnable via the [Testing block](../README.md#testing).

| | |
|---|---|
| Host tests | 105 (102 library + 3 example-lib), no GPU needed |
| Clippy warnings | 0 (`--workspace --all-targets`) |
| Demo binaries | 10, each ending at a pass/fail acceptance banner (plus the standalone [tutorial project](../examples/tutorial-fit/)) |
| `unsafe` occurrences | 15, in 5 boundary files ([../SAFETY.md](../SAFETY.md) §1) |
| Crates | 8 (~9,200 lines of Rust) |
| GPU launch overhead vs Warp | 1.1–3.0× lower in 11 of 12 cells |
| Ray-march CPU/GPU parity | 99.88 % of pixels < 1e-4 |
| Full differentiable-fitting acceptance run | 1.08 s wall |
